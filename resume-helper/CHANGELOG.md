# 이력서 도우미 개선 내역 (v10.4)

이전 버전(7차: 말풍선 따라 쓰기 투어)과 비교해 무엇이 좋아졌는지 정리했습니다.
- 기존 기능은 하나도 빠지지 않았습니다. 자리만 옮긴 것은 "고급 기능 열기" 안에 그대로 있습니다.
- 이전에 쓰던 내용과 백업 파일도 그대로 쓸 수 있습니다.
- 지금 버전은 화면 오른쪽 위에 표시됩니다 (`v10.4`).

## 한눈에 보기

| 구분 | 이전 | 지금 |
|---|---|---|
| 시작 화면 | 패널 버튼 30개 이상 | **3단계**(고르기 → 고치기 → PDF 저장)만 보이고, 나머지는 접혀 있음 |
| 처음 채우기 | 예시 문구에서 직접 시작 | **주제·역할을 고르면** 이력서가 예시로 채워짐 |
| 이력서 칸 | 기본 칸만 | **나이, 병역, 기타 문서, 기술 분류** 추가 |
| 빈 칸 | 지워도 점·동그라미·빈 칸이 남음 | 지우면 **접히고**, 버튼으로 되살림 |
| PDF 속 주소 | 눌러도 안 열림 | **모든 http·https 주소와 이메일**이 눌림 (휴대폰 포함) |
| 다른 양식 | 없음 | **사람인·잡코리아·호주·미국·일본** 양식으로 자동 변환해 PDF 저장 |
| A4 초과 경고 | 1쪽인데도 초과라고 경고하는 등 실제와 다름 | 실제 PDF와 거의 같음 (최대 1~2줄 먼저 경고) |
| 필수 조건 | 학력 정보·성과 숫자가 필수 (안 쓰면 빨간 경고, PDF 저장 막힘) | **둘 다 선택**. 학력 칸은 비우면 접힘 |
| 자동 테스트 | 20개 | 59개 |

## 1. 쓰기 쉬워졌습니다 — 간단 모드

**학생이 보는 흐름**
1. **주제·역할 고르기**
   - 주제 4개(맛집 리뷰, 여행 코스, 고객 관리 CRM, 세미 프로젝트) 중 하나와 역할을 고르면 이력서가 예시로 채워집니다.
   - 채워지는 칸은 한 줄 소개, About Me, 기술 스택, 대표 프로젝트, 자기소개입니다.
   - 이름·연락처·교육·자격증은 건드리지 않습니다.
2. **내 것으로 고치기**
   - 채운 직후 말풍선 투어가 시작됩니다. 이름·숫자·링크를 자기 것으로 바꿉니다.
3. **점검하고 PDF 저장**

**함께 바뀐 것**
- 질문형 가이드, AI 점검·자동 입력, 취업 준비 도구, 디자인, 버전 관리, 백업은 "⚙️ 고급 기능 열기" 안에 있습니다. 열고 닫은 상태는 기억됩니다.
- 간단 모드에서는 이력서의 회색 안내 문구와 분량 배지를 숨겨 화면이 단순합니다.
- 이미 내용을 쓴 이력서를 예시로 채우려 하면 먼저 확인합니다. 실수해도 "방금 변경 되돌리기"로 복구됩니다.

## 2. 이력서 칸이 늘었습니다

- **나이:** 이름 옆 작은 글씨 칸입니다. 예: `만 25세`
- **병역:** 연락처 줄의 한 칸입니다. 예: `병역: 군필 (육군 병장 만기전역, 2019.03 ~ 2020.09)`
  - 예시 라이브러리 "병역" 탭에 예시 11개가 있습니다(육·해·공·해병·사회복무·미필·면제 등).
- **기타 문서:** AI 코드 검증일지, 디버깅 일지 같은 문서를 "문서명 · 링크 · 한 줄 설명"으로 적는 섹션입니다.
  - 행 추가·삭제, 섹션 숨기기가 됩니다.
  - 예시 12개가 있습니다(결과보고서, 시연 영상, 배포 주소, ERD 등).
  - 파일은 PDF에 들어가지 않으므로 공개 링크로 적습니다.
- **기술 스택 분류:** "+ 기술 스택 추가"를 누르면 분류 목록이 열립니다.
  - 분류: 클라우드·인프라, AI, 테스트, 보안·인증, 협업·도구, 모니터링·기타, 직접 입력
  - 고르면 분류 이름과 대표 기술이 든 행이 생깁니다.
- **말풍선 투어:** "나이·병역", "기타 문서" 단계가 추가되어 19단계가 되었습니다.
- 나이·병역은 공개 저장소에 올리는 포트폴리오 README에는 넣지 않습니다.

## 3. 지워지지 않던 칸을 고쳤습니다

| 이전 증상 | 지금 |
|---|---|
| 블로그·사람인 칸을 비워도 연락처 줄 끝에 점 2개가 남음 | 빈 칸은 접힘. "+ 블로그" 같은 버튼으로 되살림 |
| 지원 배지를 비우면 사진 옆에 남색 동그라미가 남음 | 접힘 ("+ 지원 배지"로 되살림) |
| 프로젝트 2·3, 교육·자격증 기본 행은 삭제 버튼이 없어 빈 칸이 남음 | 모든 선택 행에 삭제 버튼이 있음 (첫 교육 행과 대표 프로젝트만 남음) |

- 예시 문구가 그대로인 칸은 안내용이라 접지 않습니다. 직접 지운 칸만 접습니다.
- 지운 칸은 빠른 점검·PDF 점검의 필수 항목에서 빠집니다. 지운 칸 때문에 PDF 저장이 막히지 않습니다.

## 4. PDF에서 주소를 누르면 열립니다

**쓰는 법**
1. "PDF로 저장하기" → "인쇄 화면 열기"를 누릅니다.
2. 대상을 "PDF로 저장"으로 고릅니다.
3. 저장한 PDF에서 주소를 누르면(휴대폰은 손가락으로 터치) 열립니다.

**동작 방식**
- `http://`·`https://`로 시작하는 모든 주소가 링크가 됩니다.
- `github.com/…`·`velog.io/…`처럼 앞부분이 빠진 주소도 링크가 됩니다.
- 이메일은 누르면 메일 쓰기 창이 열립니다.
- 주소 앞뒤에 괄호·마침표·조사가 붙어 있어도 주소만 링크가 됩니다. 예: `(https://…)와`, `…/post에서`
- 예시 문구(`[ ]`)가 섞인 주소와 위험한 주소(`javascript:` 등)는 링크로 만들지 않습니다.
- 저장된 이력서 내용은 바뀌지 않습니다. 링크는 인쇄하는 동안에만 붙습니다.

## 5. 채용 사이트 양식 5종으로 바꿔 PDF로 저장합니다

3단계 패널의 "🌏 사람인·잡코리아·해외 양식 PDF"에서 엽니다. 입력한 내용으로 자동으로 채운 문서가 바로 보입니다.

| 양식 | 언어 | 특징 |
|---|---|---|
| 사람인 | 한국어 | 기본정보(사진·나이) → 학력 → 교육 → 프로젝트 → 자격증 → 스킬 → 포트폴리오 → 병역 표 → 자기소개서 |
| 잡코리아 | 한국어 | 인적사항 → 학력 → 교육 → 자격증 → 스킬 → 포트폴리오 → 병역 → 자기소개서 → 경력기술서 |
| 호주 | 영어 | 사진·나이 없음. 비자(Work rights) 줄과 Referees 줄 |
| 미국 | 영어 | 사진·나이·생년월일 없음. Summary → Skills → Projects → Education |
| 일본 | 일본어 | 履歴書(사진·満年齢·学歴/職歴 年月 표) + 職務経歴書 |

**자동으로 바꿔 주는 것**
- 이름 로마자: `홍길동 → Gildong Hong`
- 국제 전화번호: `010-1234-5678 → +82 10-1234-5678`, `02-1234-5678 → +82 2-1234-5678`
- 날짜: `2026.11 → Nov 2026 / 2026年11月`
- 졸업·중퇴·수료(예정) 구분
- 병역: `육군 병장 만기전역 → Republic of Korea Army, Sergeant — Honorable discharge / 大韓民国陸軍 兵長 満期除隊`

**번역 (영어·일본어 양식)**
- Chrome 내장 번역이 있으면 탭을 열 때 바로 번역합니다. 무료이고 기기 안에서 번역합니다.
- 내장 번역이 안 되면 "번역하기" 버튼으로 AI 번역(OpenRouter API 키 필요)을 씁니다.
  - AI 번역은 사용량이 들기 때문에 버튼을 눌렀을 때만 씁니다.
  - 연락처는 가리고 보냅니다.
  - 원문의 숫자가 빠지거나 바뀐 번역은 버립니다.
- 번역 결과는 기억되어 같은 문장을 다시 번역하지 않습니다.
- 번역하지 못한 문장은 주황색으로 남습니다. 문서에서 직접 고쳐 쓰면 됩니다.

**고치기와 저장**
- 미리보기 문서를 눌러 바로 고칠 수 있습니다. 원래 이력서는 그대로이고, 양식별로 기억합니다. "다시 만들기"로 되돌립니다.
- **노란 칸**은 이력서에 없는 정보(주소·생년월일·비자 등)입니다. 채우지 않으면 PDF에서 빠집니다.
  - 일본 양식의 생년월일처럼 손으로 적는 칸은 빈칸으로 남습니다.
- "이 양식 PDF로 저장" 또는 "5개 양식 한 번에 PDF"로 저장합니다. 문서 속 주소도 누를 수 있습니다.

## 6. 그 밖에 고친 문제

- PDF에서 머리글이 휴대폰 모양(세로)으로 쌓이던 문제. 고친 뒤 같은 내용이 1쪽에 4줄 더 들어갑니다.
- "A4 초과" 경고가 실제 PDF와 다르던 문제. 디자인 3종·사진·섹션 숨김 조합마다 실제 PDF와 비교해 맞췄습니다.
- 양식 미리보기를 고치면 이력서의 되돌리기 기록과 자동 저장이 함께 움직이던 문제.
- 내장 번역이 응답하지 않으면 "번역 중"에서 멈추던 문제. 이제 시간이 지나면 멈추고 안내합니다.
- 번역 중에 다른 양식 탭으로 옮기면 그 탭에서 고친 내용이 지워지던 문제.
- 행 삭제 버튼을 누른 직후 칸이 접히지 않던 문제.

## 알아 두면 좋은 점

- 입력한 내용은 **쓰고 있는 브라우저에만** 저장됩니다. 다른 컴퓨터로 옮길 때는 "고급 기능 → 파일로 내보내기"를 씁니다.
- 채용 사이트 양식은 각 사이트의 공식 파일이 아닙니다. 항목 순서와 관례를 맞춘 문서이고, 사이트 로고나 이름은 넣지 않습니다.
- 번역된 문장은 저장하기 전에 숫자와 기술 이름이 맞는지 한 번 확인하세요.
